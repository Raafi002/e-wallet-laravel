# UTS IAE/EAI – Digital Payment Service (E-Wallet)

Struktur zip ini berisi *kode inti* untuk 2 service Laravel dan 1 API Gateway Node.js.

> Penting: Laravel full framework & folder `vendor` **tidak** disertakan agar ukuran tetap kecil.
> Untuk menjalankan, buat project Laravel baru (`composer create-project`) lalu salin file-file di folder ini
> sesuai petunjuk di masing-masing README service.

## Struktur

- `user-service/` – kode untuk User Service (Laravel)
- `payment-service/` – kode untuk Payment / Wallet Service (Laravel)
- `api-gateway/` – API Gateway (Node.js + Express)
